# [TM01] Create a team member as a draft or publish immediately

Source: https://github.com/AI-for-QC/Issues/issues/1

Acceptance criteria in the source issue are unnumbered checkboxes. They are listed below in source order so they can be numbered AC-1 onward.

## User story

As an Admin, I want to create a team member profile, manage its photo, and either save it as a draft or publish it, so that I can prepare and publish complete team information in one workflow.

## Description

Create a team member profile using the «Додати в команду» form. Enter and validate profile details, manage the photo, and choose whether to save a draft or publish immediately.

## Preconditions

- The Admin is in the Team administration area.
- At least one team category exists.

## Form

| Field | Control | Required | Limit |
| --- | --- | --- | --- |
| Категорія | Drop-down. Placeholder «Оберіть категорію» | Mandatory | One category that already exists in the system |
| Ім'я та Прізвище | Text | Mandatory | Char(50) |
| Опис | Text | Optional for a draft, mandatory for publication | Char(200) |
| Фото | Image upload | Optional for a draft, mandatory for publication | jpeg, jpg, png, webp; maximum 3 Mb; recommended 320×400 |

## Validation

| Field | When | Rule | Message |
| --- | --- | --- | --- |
| Ім'я та Прізвище | While typing | Maximum 50 characters. Further input is blocked | Не більше 50 символів |
| Ім'я та Прізвище | While typing | Only letters, apostrophe ('), hyphen (-) and space | Поле може містити лише літери, пробіли, ’ - |
| Ім'я та Прізвище | While typing | Digits are not allowed | Поле не може містити цифри |
| Ім'я та Прізвище | On blur | Minimum 2 characters | Не менше 2 символів |
| Ім'я та Прізвище | On blur | Not empty | Поле обов'язкове |
| Опис | While typing | Maximum 200 characters. Further input is blocked | Не більше 200 символів |
| Опис | On blur | Minimum 10 characters | Не менше 10 символів |
| Опис | On blur | Not empty | Поле обов'язкове |
| Категорія | On blur | Not empty | Поле обов'язкове |
| Категорія | On submit | Exactly one category, and it is stored in the system | Учасник команди може належати лише до однієї категорії. |

Spaces:

- During input, replace consecutive spaces with a single space.
- On save, trim both ends and replace consecutive spaces with a single space.
- Do not count spaces before text as valid characters.
- Treat a value that contains only spaces as empty.

## Acceptance criteria

- AC-1: Clicking «Додати в команду» opens the modal titled «Додати в команду». All fields are empty and editable. «Зберегти як чернетку» and «Опублікувати» are disabled. X is active.
- AC-2: The form matches the [profile form](https://www.figma.com/design/mZTSCb4NVC31facfhy6Gu1/dashboard?node-id=180-1224&t=OdqvPPBhPf1vlJDp-4) and the [additional state](https://www.figma.com/design/mZTSCb4NVC31facfhy6Gu1/dashboard?node-id=180-1290&t=OdqvPPBhPf1vlJDp-4).
- AC-3: The form contains the fields from the table above.
- AC-4: «Ім'я та Прізвище» and «Опис» show a live used/maximum character counter.
- AC-5: Validation messages match the [field validation](https://www.figma.com/design/mZTSCb4NVC31facfhy6Gu1/dashboard?node-id=281-751&t=OdqvPPBhPf1vlJDp-4) frame and the validation table above.
- AC-6: If every field is empty, X closes the modal immediately.
- AC-7: If at least one field is non-empty, X shows «Зміни будуть втрачені. Бажаєте продовжити?». «ТАК» closes the popup and the create modal without saving. «НІ» closes only the popup and keeps the entered values.
- AC-8: The «Фото» section matches the [photo section](https://www.figma.com/design/mZTSCb4NVC31facfhy6Gu1/dashboard?node-id=279-828&t=OdqvPPBhPf1vlJDp-4). The media-icon hover state matches the [hover mock-up](https://www.figma.com/design/mZTSCb4NVC31facfhy6Gu1/dashboard?node-id=593-1159&t=J9yNRuuc7WPn0fZp-4).
- AC-9: An image can be chosen from the file dialog or dragged onto the media icon.
- AC-10: A file larger than 3 Mb highlights the field, shows «Фото не більше 3 Mb», and is not uploaded.
- AC-11: A file whose format is not jpeg, jpg, png or webp highlights the field, shows «Невірний формат фото, дозволено jpeg, jpg, png, webp», and is not uploaded.
- AC-12: After successful validation, the file is uploaded and shown in the media icon.
- AC-13: Clicking the image Delete icon in its hover state shows «Видалити фото?». «НІ» closes the popup. «ТАК» deletes the image and restores the enabled [empty Photo section](https://www.figma.com/design/mZTSCb4NVC31facfhy6Gu1/dashboard?node-id=279-884&t=cnJk1oTYnO97Kj5Z-4).
- AC-14: An uploaded image larger in pixels than the designed size immediately opens the [cropper modal](https://www.figma.com/design/mZTSCb4NVC31facfhy6Gu1/dashboard?node-id=5768-7616&t=R2C82pAWaEyiFlZ1-4).
- AC-15: Cropping follows the [Cropper specification](https://github.com/ita-social-projects/VictoryCenter-Back/wiki/Cropper) and the [image-management enhancement](https://github.com/ita-social-projects/VictoryCenter-Back/wiki/Enhancements#cropper).
- AC-16: «Зберегти як чернетку» becomes enabled when «Ім'я та Прізвище» and «Категорія» are non-empty and valid.
- AC-17: «Зберегти як чернетку» shows «Зберегти нового члена команди?». «НІ» closes the popup and «Додати в команду» without saving.
- AC-18: On «ТАК», the profile is created with status «Чернетка», the modal closes, and the Draft appears last in its category tab in the admin Team view.
- AC-19: «Опублікувати» becomes enabled when every field is non-empty and valid. Description and Photo are mandatory for publication.
- AC-20: «Опублікувати» shows the confirmation titled «Підтвердження» with «Опублікувати нового члена команди?». «НІ» closes only that popup.
- AC-21: On «ТАК», the profile is created with status «Опубліковано», the modal closes, and «Не забудь встановити порядок відображення» closes automatically after 3 seconds.
- AC-22: The published profile is last in its category tab in the admin Team view and last in that category on the public Team page.
