# Declining draft save leaves the create modal open

## Preconditions

- The confirmation «Зберегти нового члена команди?» is open over the «Додати в команду» modal.
- Test data: «НІ».

## Steps to reproduce

1. Click «НІ».

## Expected result

The «Додати в команду» modal is closed.

Source: [TD-131](../test-design.md#td-131-declining-draft-save-closes-the-create-modal) in `docs/test-design.md`.

## Actual result

«НІ» closes only the popup. The create modal stays open with the entered values, and nothing is saved.

Recorded in the healer run report. The later Playwright list/HTML run (`27 passed, 0 failed, 6 skipped`) has no assertion error for this test: `test.fixme()` skipped it before the expect, and the report result has `errors: []`.
