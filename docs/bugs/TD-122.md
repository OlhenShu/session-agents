# Draft stays disabled at the name minimum when «Опис» is empty

## Preconditions

- The «Додати в команду» modal is open.
- «Опис» is empty.
- No photo is chosen.
- The category «Керівництво» exists.
- Test data: name «Ан». Category «Керівництво».

## Steps to reproduce

1. Type «Ан» into «Ім'я та Прізвище».
2. Leave «Ім'я та Прізвище».
3. Choose «Керівництво».

## Expected result

«Зберегти як чернетку» is enabled.

Source: [TD-122](../test-design.md#td-122-draft-becomes-enabled-at-the-name-minimum) in `docs/test-design.md`.

## Actual result

With name «Ан», a category and an empty «Опис», the draft button stays disabled. It only enables once «Опис» is filled.

Recorded in the healer run report. The later Playwright list/HTML run (`27 passed, 0 failed, 6 skipped`) has no assertion error for this test: `test.fixme()` skipped it before the expect, and the report result has `errors: []`.
