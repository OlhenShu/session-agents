# Draft save stores the description with its spaces unchanged

## Preconditions

- GET /api/TeamCategories returns an item whose name is «Керівництво».
- No stored team member has fullName «Богдан Мельник».
- Test data: fullName «Богдан Мельник». description «  Опис  текст  » (two leading spaces, two spaces between the words, two trailing spaces). categoryId of the category named «Керівництво».

## Steps to reproduce

1. GET /api/TeamCategories and take the id of the item whose name is «Керівництво».
2. POST /api/TeamMembers with fullName «Богдан Мельник», that categoryId, and description «  Опис  текст  ».
3. GET /api/TeamMembers/search with FullName «Богдан Мельник».

## Expected result

An entry in items has description «Опис текст».

Source: [TD-140](../test-design.md#td-140-draft-save-trims-and-collapses-the-description) in `docs/test-design.md`.

## Actual result

The description is stored exactly as sent, «  Опис  текст  ».

Recorded in the healer run report. The later Playwright list/HTML run (`27 passed, 0 failed, 6 skipped`) has no assertion error for this test: `test.fixme()` skipped it before the expect, and the report result has `errors: []`.
