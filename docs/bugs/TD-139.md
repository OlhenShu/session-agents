# Draft save keeps the inner double space in the name

## Preconditions

- GET /api/TeamCategories returns an item whose name is «Керівництво».
- No stored team member has fullName «Анна Марія».
- Test data: fullName «  Анна  Марія  » (two leading spaces, two spaces between the words, two trailing spaces). categoryId of the category named «Керівництво».

## Steps to reproduce

1. GET /api/TeamCategories and take the id of the item whose name is «Керівництво».
2. POST /api/TeamMembers with fullName «  Анна  Марія  » and that categoryId.
3. GET /api/TeamMembers with CategoryId of that category.

## Expected result

An entry in items has fullName «Анна Марія».

Source: [TD-139](../test-design.md#td-139-draft-save-trims-and-collapses-the-name) in `docs/test-design.md`.

## Actual result

The name is trimmed at the ends, but the inner double space stays, so the stored name is «Анна  Марія».

Recorded in the healer run report. The later Playwright list/HTML run (`27 passed, 0 failed, 6 skipped`) has no assertion error for this test: `test.fixme()` skipped it before the expect, and the report result has `errors: []`.
