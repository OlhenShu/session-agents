# Name blocks the 51st character but does not show «Не більше 50 символів»

## Preconditions

- The «Додати в команду» modal is open.
- «Ім'я та Прізвище» contains 50 characters «А».
- Test data: next character «Б». Message «Не більше 50 символів».

## Steps to reproduce

1. Type «Б» into «Ім'я та Прізвище».

## Expected result

The message «Не більше 50 символів» is shown.

Source: [TD-029](../test-design.md#td-029-name-blocks-the-51st-character) in `docs/test-design.md`.

## Actual result

The 51st character is blocked and the counter stays 50/50, but «Не більше 50 символів» never appears.

Recorded in the healer run report. The later Playwright list/HTML run (`27 passed, 0 failed, 6 skipped`) has no assertion error for this test: `test.fixme()` skipped it before the expect, and the report result has `errors: []`.
