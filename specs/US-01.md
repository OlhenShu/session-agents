# US-01 UI checks

## Application Overview

UI plan for [TM01] Create a team member as a draft or publish immediately. It covers the 20 UI checks that remain in docs/test-design.md, in that order. Each scenario is one of those checks. API checks and TBD checks are not included. Each scenario starts from a fresh state. Seed file: tests/seed.spec.ts.

## Test Scenarios

**Seed:** `tests/seed.spec.ts`
